## 📱 MediFast HealthCare Mobile App (React Native)

A modern **patient-focused mobile application** built with React Native to provide seamless healthcare access anytime, anywhere.

### ✨ App Features
- Patient appointment booking system  
- Doctor browsing & details view  
- Ambulance request system  
- User-friendly Bangla UI support  
- Fast & responsive mobile experience  
- Real-time healthcare access
